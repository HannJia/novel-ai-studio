## 1. 首页（对应效果图第 3 张）

### 布局

```
┌────────┬──────────────────────────────────────────────┬──────────────┐
│ 全局   │  问候语 + 每日目标进度    12 周写作热力图      │  待办        │
│ 导航   ├──────────────────────────────────────────────┤  ─────────   │
│        │  继续写作卡片（大字 + 封面 + 摘要 + CTA）      │  云同步状态  │
│        ├──────────────────────────────────────────────┤  ─────────   │
│        │  我的书架（5 本书 + 新建卡）                   │  名言卡      │
└────────┴──────────────────────────────────────────────┴──────────────┘
```

三栏：全局导航 200px（可折叠至 64px）、主区自适应、右栏 280px。

### 各区块规格

**问候语**：按时段变化（早上好 / 下午好 / 晚上好），`--font-size-display`，
后接「今天写了 N 字」，数字用主色。**不用逗号分隔千位以外的修饰**，效果图是「2,140 字」。

**每日写作目标**：进度条 + 「2,140 / 3,000」。
- 目标值来源：用户设置，默认 3000 字
- 进度条：轨道 `--progress-track`，填充 `--progress-fill`，高 4px，圆角全圆
- 超过目标时：填充色改为 `--color-success`，并显示「已达成」

**12 周写作热力图**：横轴周、纵轴星期（7 行 × 12 列）。
- 五级灰阶由浅到深，第五级用主色
- 悬停显示 tooltip：日期 + 当日字数
- 数据来源：章节的创建/修改时间聚合出的**每日净增字数**。
  **实现方注意**：现有库中没有「每日字数快照表」，需要从章节内容长度 + 修改时间推算。
  这是个需要和各章的 revision 记录对齐的活，**如果成本过高，允许降级为「每日修改章节数」**，
  但必须在代码注释和 CHANGELOG 中说明降级。

**继续写作卡**：封面缩略图（无封面时用书名文字生成的占位封面）+ 书名 + 类别标签 +
最近一章的正文摘要（**取最近编辑章节的最后 200 字，不要用 AI 生成摘要**，
避免首页加载触发模型调用）+ 「第 N 章 · 3 分钟前」+ 主按钮。

**我的书架**：封面网格，每本显示书名、字数（`128,463 字`）、完成进度百分比条。
右上角排序下拉（按最近编辑 / 按创建时间 / 按字数）。
末尾是虚线框「+ 新书」卡，点击进 `/create`。

**待办面板**：三类条目，每条可点击跳转到对应审批界面：
- 「N 项待确认数据变更」→ 设定集右侧更新面板
- 「N 个同步冲突」→ 云同步面板
- 无待办时整块隐藏（**不要显示「暂无待办」占位**，效果图是有内容的状态）

**云同步状态卡**：状态点（已同步绿 / 同步中黄 / 冲突红 / 离线灰）+ 上次同步时间。

**名言卡**：静态文案 + 印章图形。可以作为用户设置项（自定义扉页语），
默认值「好的故事，值得被认真对待。」

### 首页特有状态

- **新用户无书**：书架区只剩「+ 新书」卡，继续写作卡隐藏，
  待办面板隐藏，热力图显示全空。**不要显示大段引导文案**。
- **只有 1 本书**：书架网格左对齐，不拉伸卡片。

## 2. 设定集 · 人物详情页（对应效果图第 1 张）

### 布局

```
┌─────────────┬──────────────────────────────────────┬─────────────────┐
│ 设定集二级  │ 面包屑                                │ 来自正文的更新   │
│ 导航        │ 人物头像 │ 姓名 + 别名 + 简介           │ (N)             │
│ 人物 24     ├──────────────────────────────────────┤ ─────────       │
│ 地点 12     │ 基础属性表                            │ 变更卡 1        │
│ 势力 6      │ 装备物品（卡片行）                    │ 变更卡 2        │
│ 物品·装备 18│ 人物关系图 │ 出场与事件               │ 变更卡 3        │
│ 世界规则 9  │                                      │                 │
│ 资料库 2    │                                      │                 │
└─────────────┴──────────────────────────────────────┴─────────────────┘
```

三栏：二级导航 240px、主区自适应、更新面板 320px（可折叠）。

### 基础属性表（关键组件）

五列：属性名 / 基础值 / **有效值** / 来源加成。

- **有效值**用主色加粗，是「基础值 + 所有加成」的实时计算结果
- 来源加成是一个个可悬停的标签，悬停显示来源（装备名 / 技能名）和数值
- 数值变动时（审批通过后）用一次 300ms 的高亮闪烁提示，**不要持续动画**

**数据来源**：读取数据面板模块的数值 + 装备模块的加成，在前端计算。
**不要在库里存「有效值」**，它是派生值。

### 装备物品

横向卡片行，每张：图标 + 名称 + 类别标签 + 加成摘要。
类别：武器 / 防具 / 饰品 / 秘籍（效果图四种，实现时以现有数据为准）。

### 人物关系图

小规模关系图（中心人物 + 周围 N 人），关系用带标签的连线
（暧昧 / 师徒 / 宿敌…）。
**现有代码是否有关系图实现需实现方核查**；如果没有，本轮**可以用简化版**：
中心人物居中，关系人以列表 + 关系标签呈现，图形化关系图列为后续阶段
（见 `08-rollout.md`）。

### 出场与事件

章节列表，每行：第 N 章 + 事件描述 + 右箭头跳转到该章。
数据来源：章节内容中该角色的出现记录（复用现有实体识别结果）。

### 来自正文的更新面板（审批界面）

三条变更卡，每张包含：

1. 变更类型图标 + 类型名（攻击力 数值变更 / 装备获得 新增 / 关系变化 关系调整）
2. 「待确认」标签
3. 变更摘要：`原值: 100 → 新值: 130`（原值灰、新值主色加粗）
4. 来源：第 N 章
5. **证据片段**：引用原文的完整句子，用引号包裹
6. 操作：「确认」（主按钮）/「忽略」（次按钮）

**规则**：
- 「确认」写入**对应模块的表**（数值变更写数据面板，装备写装备模块，
  关系写关系模块），**不是写同一张表**
- 「忽略」不改数据，但**要记录忽略状态**，避免同一处原文反复提示
- 面板标题 `(3)` 是待确认数量，处理后实时更新
- 全部处理完：面板显示「已全部处理」+ 淡出，或整体隐藏（见 `09-open-questions.md`）

**对比视图缺失**：效果图只画了单条变更卡，没有「章节版本对比（diff）」界面。
diff 规格见 `05-missing-pages.md` 第 3 节。

## 3. 写作页 · 浅色（对应效果图第 2 张）

### 布局

```
┌────────┬────────────┬────────────────────────────────┐
│ 全局   │ 章节目录    │ 正文（居中单栏，最大宽 720px）  │  ← 批注卡浮在右侧
│ 导航   │ (可折叠)    │                                │     空白区或覆盖在
│        │            │  [灰色续写建议字]               │     正文右缘
│        │            │  ────────────────────────────  │
│        │            │  续写 │ 改写 │ 审查 │ 专注      │
└────────┴────────────┴────────────────────────────────┘
```

**关键点**：正文只有一栏，没有常驻的 AI 聊天侧栏。
AI 以两种形式出现：

1. **页边批注**：浮在正文右侧，有连线指向原文（规格见 `02-components.md` 第 2.6 节）
2. **行内续写建议**：正文末尾的灰色建议文字，Tab 采纳（规格见 `06-interactions.md`）

### 顶部信息栏

面包屑（笔名 › 我的作品 › 书名 › 卷名 › 章节名）+ 右侧「3,256 字 · 故事第 38 天 · 已保存」
+ 命令面板按钮。

**「已保存」三态**：已保存 / 保存中（转圈）/ 保存失败（红字 + 重试入口）。
复用现有 `SaveStatusBar.vue`。

**「故事第 38 天」**：故事内时间，不是现实时间。
来源是故事地图的时间轴数据。**无数据时不显示这一项**，不要显示「故事第 0 天」。

### 底部操作栏

四个按钮居中悬浮：续写 / 改写 / 审查 / 专注。

- **专注**：进入专注模式，隐藏章节目录和批注，只留正文。
  退出方式必须明显（Esc 或右上角退出按钮）
- 这四个按钮在 AI 生成过程中变为「停止」或显示进度

### 批注交互

- 批注卡与正文锚定（见 `06-interactions.md` 第 2 节）
- 「采纳」「忽略」两个操作
- 同一个位置有多条批注时，只显示第一条，其余折叠
- 正文滚动时批注跟随（按锚点位置计算，不是 fixed 定位）

### 本页特有状态

- **无批注**：右侧不显示任何东西，不要显示「暂无批注」
- **AI 审查进行中**：批注区域显示一个 spinner 和「审查进行中…」
- **正在流式续写**：正文末尾建议字逐个出现，同时底部按钮变「停止生成」

## 4. 写作页 · 深色 + 命令面板（对应效果图第 4 张）

深色是 `data-theme="dark"`，不是独立页面。命令面板是本张图的主要内容。

### 命令面板

`Ctrl+K`（Windows）/ `Cmd+K`（macOS）呼出。**注意**：现有代码没有 `Ctrl+K` 绑定，
（实测现有快捷键只有 `Ctrl+S`、`Ctrl+Enter`、`Esc`），不会冲突。

分组与条目（效果图给出了 7 条）：

| 分组 | 条目 | 说明 |
| --- | --- | --- |
| 写作 | 续写 500 字 | `Ctrl+1` |
| 写作 | 按章节计划续写 | `Ctrl+2` |
| 写作 | 改写选段为更紧张的节奏 | `Ctrl+3` |
| 审查 | 审查本章一致性 | `Ctrl+4` |
| 审查 | 检查违禁词 | `Ctrl+5` |
| 跳转 | 第 N 章 · 章节名 | `Ctrl+6` |
| 跳转 | 设定集 · 角色名 | `Ctrl+7` |

**快捷键说明**：效果图标的是 `⌘1`–`⌘7`（macOS 风格）。
Windows 下应为 `Ctrl+1`–`Ctrl+7`。
**但要小心**：`Ctrl+1`–`Ctrl+9` 在部分浏览器/环境下是标签页切换，
Electron 里不冲突，但**需要实现方实测**。

**搜索行为**：
- 输入即时过滤（客户端过滤，不要每次按键都请求后端）
- 章节和设定条目的搜索走已有的语义索引（`src/services/semanticIndex.ts`），
  **注意不要在主线程同步执行**，需要防抖 + 异步
- 无结果时显示「没有匹配的结果」+ 提示可用的操作

**中文输入法**：命令面板的搜索输入框在组词期间**不得触发快捷键匹配**
（如输入「续写」时按到 `x` 不应误触）。复用 `InspirationChat.vue` 的
`event.isComposing || keyCode === 229` 判断。

### 深色模式注意

- 正文纸面 `--bg-color-paper` 是 `#262120`，**不是纯黑**。纯黑 + 白字在长时间阅读下
  对比度过高，会产生光晕感
- 正文文字色不要用纯白，用 `--text-color-primary`（`#EDE7E0`）

**这是效果图里最复杂的页面**，且现有代码没有对应实现。

### 横向画布

- 横轴是章节号标尺（1, 2, 3…），上方按卷分组显示卷名
- 每个故事线占一行，行左侧是线名 + 一句话描述
- 节点是方块，内含章节号
- 三种节点态（见 `01-tokens.md` 第 1 节新增语义色）：

**性能警告**：效果图有约 60 个章节 × 5 条线。如果节点数超过 200，
需要虚拟化或只渲染可视区域。**实现方必须先做性能测试再铺量**。

### 视图切换

三个视图：**结构**（默认，按故事线分行）/ **弧线**（按情绪曲线）/ **时间**（按故事内时间轴）。

**实现方注意**：效果图只画了「结构」视图。
「弧线」和「时间」的规格**未定义**，**本轮不实现**，按钮置灰并加 tooltip
「即将支持」。不要自行发挥设计。

### 节点详情面板

右侧 320px，包含：节点标题 + 类型标签 + 描述 + 目标 + 关键情节（有序列表）+
关联角色（标签，可点跳转到设定集）+ 节点类型图例。

底部两个按钮：「生成章节计划」（主）/「编辑」（次）。

### 故事时间轴

底部独立区域，显示故事内时间的里程碑点。
**如果现有数据没有故事内时间字段**，这一块**允许降级为不显示**，
但需要在 `09-open-questions.md` 中确认是否要新增该字段。
**不要伪造时间数据**。

### 本页特有状态

- **书籍刚创建、无章节**：画布显示空标尺 + 「还没有章节」提示 +
  「生成大纲」引导按钮
- **章节数 > 60**：章节号标尺需要抽稀显示（每 5 章显示一个标签）

## 6. 灵感工作室（对应效果图第 6 张）

### 布局

左右分栏：左 50% 对话区、右 50% 设定板。**中间有可拖拽分隔条**。

### 左侧：对话区

- 顶部标题 + 副标题
- 消息流：用户消息（圆点 + 「你」）与 AI 消息（齿轮图标 + 「AI」）
- **长对话折叠**：效果图中「较早的 18 条对话已压缩为摘要」——
  需要一个折叠条，点击展开。折叠阈值建议 20 条
- 底部输入框 + 两个开关：「联网」「参考资料」+ 上下文占用指示（「上下文 42%」）
- 上下文占用超过 80% 时，进度条变 `--color-warning`，提示用户

### 右侧：设定板

- 卡片墙，每张卡片有**图钉图标**（视觉元素，红/绿）表示分类
- 六类卡片：书名候选 / 主角 / 世界观 / 金手指 / 核心冲突 / 开篇钩子
- 「刚刚整理」高亮卡：`--color-primary` 描边 + NEW 角标
- 每张卡：「编辑」「丢弃」两个操作
- 顶部「+ 添加卡片」

底部三个按钮：「我来主笔」「AI 起笔」「以此开书」。

**按钮语义需要明确**：
- **我来主笔** → 直接创建书籍，进入编辑器，AI 不预生成内容
- **AI 起笔** → 创建书籍 + AI 生成第一章草稿
- **以此开书** → 创建书籍 + 生成完整大纲，进入故事地图

### 本页特有状态

- **起始状态**：右侧设定板为空，显示「和 AI 聊聊你的故事，我来整理设定」+ 输入框聚焦
- **AI 生成中**：消息流显示流式输出（不是整段等待）
- **创建书籍中**：按钮进入 loading，**禁止重复点击**（会创建多本书）

## 7. 六个页面的共同要求

1. 所有页面在 **1024×700** 下可用（见 `06-interactions.md`）
2. 所有页面响应四套主题（`fanqie` / `eyecare` / `dark` + 系统跟随）
3. 所有按钮和交互元素实现六态（见 `02-components.md` 第 1 节）
4. 所有列表实现空/加载/错误/离线四态（见 `05-missing-pages.md` 第 5 节）
