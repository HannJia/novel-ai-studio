# 08 · 分阶段实施顺序与验收标准

## 0. 排序原则

1. **先做地基**：变量、组件规范、路由重定向。这些不做完，后面每个页面都要返工。
2. **先保留可用**：每个阶段结束时应用必须可运行、可写作、可发布。
   **不允许出现「切掉旧入口但新入口还没做完」的中间状态。**
3. **技术风险前置**：行内续写建议（`06-interactions.md` 第 1 节）是最高风险项，
   必须早做原型验证，不能放到最后。
4. **每个阶段独立可验收**，不依赖后续阶段。

**风险**：改 `variables.css` 会影响所有现有页面。必须逐页目视检查。

- [ ] 旧的 `768px` 断点已移除，1024×700 下手动调整窗口大小无布局错乱

## 阶段 2 · 写作页（浅色）

**范围**
- 正文单栏布局 + 可折叠章节树（`04-pages.md` 第 3 节）
- 底部四按钮操作栏（续写/改写/审查/专注）
- 悬浮批注卡（`02-components.md` 第 2.6 节）+ 连线 + 锚定（`06-interactions.md` 第 2 节）
- 专注模式
- 1024×700 下的批注抽屉折叠方案（`06-interactions.md` 第 5 节）

**风险**
- 批注锚定算法在正文大改后失效 → 必须有「已失效批注」分组，不能静默丢失
- 移除常驻 AI 聊天侧栏会削弱现有功能 → **本轮不删除 `AiChatAssistant`**，
  改为收进「审查」按钮的抽屉里，功能不丢

**验收标准**
- [ ] 三栏在 1024 / 1280 / 1440 / 1920 四档宽度下均无重叠、无溢出
- [ ] 1024px 下批注收进抽屉，**覆盖正文而非挤压**，有未处理批注时显示角标
- [ ] `Esc` 优先级链按 `06-interactions.md` 第 4.2 节工作（5 层逐个手测）
- [ ] 批注锚定测试：
      - 在锚点前插入 500 字 → 批注仍锚定正确位置
      - 删除锚点所在整段 → 批注进入「已失效」分组
      - 制造两个相同锚点文本 → 用前后文指纹消歧正确
- [ ] 正文滚动时批注跟随正确（不是 fixed 定位）
- [ ] 现有功能无回归：`AiChatAssistant`、`ChapterReviewSidebar`、
      `SaveStatusBar`、`ChapterAiStatus` 的测试全绿
- [ ] 专注模式可进可出，退出方式明显
- [ ] 四套主题下批注卡与连线均可见

## 阶段 3 · 行内续写建议（最高风险，独立验收）

**为什么单独一个阶段**：这是整套方案里技术难度最高的一项
（`06-interactions.md` 第 1 节），必须独立验证，失败时要有回退方案。

**范围**
- 按方案 A（叠加层）实现灰色建议字
- `Tab` 采纳 / `Esc` 忽略
- 中文输入法全套处理（`06-interactions.md` 第 3 节）
- 生成中断保留已生成内容

**回退方案**：如果叠加层在 125% / 150% 缩放下无法做到无感知对齐，
退回方案 C（正文下方独立建议块）并**在 CHANGELOG 中说明与设计稿的差异**，
同时把方案 B（contenteditable）列为后续独立项目。**不要硬撑一个错位 1px 的方案上线。**

**验收标准**
- [ ] 叠加层与 textarea 在 100% / 125% / 150% / 175% 四档缩放下**无可见错位**
- [ ] 滚动同步无延迟感（叠加层与 textarea 滚动位置一致）
- [ ] 选中文字时高亮正常（透明文字的选区问题已解决）
- [ ] `Tab` 采纳后能一次 `Ctrl+Z` 撤销
- [ ] **IME 三个测试路径全部通过**（`06-interactions.md` 第 3.4 节，用微软拼音实测）
- [ ] 生成中开始输入 → 生成立即停止
- [ ] 生成中断 → 已生成部分保留 + 两个恢复选项
- [ ] 切章时有未处理建议 → 静默丢弃，不弹提示
- [ ] 减少动画开启时，光标闪烁降级为静态

## 阶段 5 · 故事地图

**范围**
- 横向画布 + 故事线分行 + 章节号标尺（`04-pages.md` 第 5 节）
- 三种节点态
- 节点详情面板
- 合并大纲 / 分卷 / 剧情规划的数据
- 「弧线」「时间」两个视图**按钮存在但置灰**（规格未定义）

**风险**：性能。约 60 章 × 5 条线 ≈ 300 个节点。

**验收标准**
- [ ] **性能**：300 个节点下滚动帧率 ≥ 50fps（用 DevTools Performance 面板实测）
- [ ] 若性能不达标，实施虚拟化或可视区域裁剪，并记录实际节点上限
- [ ] 章节数 > 60 时章节号标尺抽稀显示（每 5 章一个标签）
- [ ] 当前章节的垂直红线位置正确
- [ ] 点击节点 → 详情面板加载正确数据
- [ ] 「关联角色」标签可跳转到设定集对应人物页
- [ ] 三种节点态在**灰度截图**下仍可区分（不能只靠颜色）
- [ ] 新书无章节时显示空状态 + 生成大纲引导
- [ ] 故事内时间轴：若现有数据无该字段则**不显示**，不伪造数据
- [ ] 旧路由 `outline` / `planning` / `volumes` 全部重定向到此页
- [ ] 键盘：方向键可在节点间移动，`Enter` 打开详情

## 阶段 6 · 灵感工作室 + 首页

**范围**
- 灵感工作室（`04-pages.md` 第 6 节）：对话 + 设定板
- 首页（`04-pages.md` 第 1 节）：统计 + 继续写作 + 书架 + 待办
- 三个底部按钮的语义区分（我来主笔 / AI 起笔 / 以此开书）

**风险**
- 热力图需要每日字数数据，**现有库中没有该快照表**。
  允许降级为「每日修改章节数」，但必须记录降级
- 「AI 起笔」「以此开书」会创建书籍 + 触发 AI 生成，**必须防重复点击**

**验收标准**
- [ ] 灵感工作室：对话流式输出正常，设定板卡片可编辑/丢弃
- [ ] 长对话折叠阈值（20 条）生效，摘要可展开
- [ ] 上下文占用超 80% 时变色提示
- [ ] 三个创建按钮**重复快速点击只创建一本书**（专项测试）
- [ ] 首页：目标进度超 100% 时变成功色并显示「已达成」
- [ ] 首页：无书新用户状态正确（无大段引导、无示例书、无待办面板）
- [ ] 首页：待办点击可跳转到对应审批界面，处理后数字实时更新
- [ ] 首页：热力图数据来源确认（净增字数 or 降级方案），降级时 CHANGELOG 有说明
- [ ] 首页：**加载首页不触发任何 AI 模型调用**（用网络面板确认）
- [ ] 灵感记录（书内）与灵感工作室（开书前）数据不混，按 `novelId` 是否为空区分
