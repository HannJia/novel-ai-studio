### 4.1 导入进度

- 阶段式进度：读取文件 → 解析 → 写入 → 完成
- 每个阶段显示当前/总数（如「正在处理第 12/40 页」）
- **必须可取消**，取消后清理已导入的中间数据
- 失败时保留已完成部分，报告失败项，提供重试

### 4.2 恢复界面

- 备份文件选择 + 校验（`projectBackupValidation.ts` 已有校验逻辑）
- 校验通过后展示内容摘要：书名、章节数、字数、导出时间
- **恢复是覆盖操作**，必须：
  - 二次确认，明确说明「当前数据将被替换」
  - 建议先自动导出当前数据的备份
  - 恢复过程中禁止操作

### 4.3 删除确认统一规范

现有删除操作散落在 `NovelList.vue`、`DataPanelWorkspace.vue` 等。
统一规范：

- **一级输入确认**：删除书籍/知识库（不可逆、影响大）→ 要求输入名称确认
- **二级按钮确认**：删除章节/条目 → 弹窗 + 危险色按钮
- 弹窗内只有确认和取消，**不要有「不再提示」勾选**（删除类操作不宜记忆）

## 5. 通用状态（四态，每个列表/页面都要实现）

### 5.1 空状态

- **新用户没有任何书**：首页书架区只有「+ 新书」卡，热力图全空，
  不显示大段引导文案，不显示「示例书」
- **某书无章节**：编辑器显示「这本书还没有章节」，给「新建第一章」按钮
- **搜索无结果**：明确说明搜索范围，给「清除筛选」按钮
- **列表为空**：一句话说明 + 一个主操作按钮，不要插图占位图

### 5.2 加载中

- **骨架屏优先**：列表/卡片用骨架屏，不用全屏 spinner
- 顶部有细进度条（2px，主色）表示全局加载
- 超过 3 秒仍未返回：显示文字「仍在加载…」
- 超过 10 秒：显示「加载较慢」+ 重试按钮

### 5.3 AI 流式生成中

- 流式文本直接追加显示，**不要打字机效果**
- 光标：闪烁的方块/竖线（复用现有 `ai-spinner` 风格）
- 显示「停止生成」按钮，位置固定，不要随文本移动
- 生成中断（网络错误）：
  - **保留已生成的部分**，不要清空
  - 显示「生成中断」+「继续生成」/「重新生成」两个选项
- 上下文超限时：明确提示「已达上下文上限」，并给出建议（开启摘要/分段）

### 5.4 出错

- 错误提示**必须可操作**：说清发生了什么 + 下一步能做什么
  - 差：「请求失败」
  - 好：「连接模型服务失败，请检查设置中的 API Key 是否有效」+「去设置」按钮
- 网络类错误：给重试按钮
- 配置类错误：给跳转到设置的按钮
- 数据类错误：给「导出诊断信息」入口（**诊断信息不得包含 API Key 和正文内容**）

### 5.5 离线

- Electron 应用，但云同步和 AI 功能依赖网络
- 离线时的表现：
  - 顶部状态条显示「离线模式」（灰色，不刺眼）
  - AI 相关按钮置灰，悬停提示「需要网络连接」
  - **写作、保存、本地编辑不受影响**，这一点要在界面上让用户确信
  - 云同步状态卡显示「离线，将在联网后自动同步」
