# 设计交接文档索引

本目录是「墨笺」新版界面的交接设计文档。目标读者是接手的实现方（人或 AI），
读完本目录后应当可以不问问题地开工，并且不误解术语与数据职责。

## 文档清单

| 文件 | 内容 |
| --- | --- |
| `00-scope.md` | 交接范围、命名约定、术语表、与现有代码的事实基线 |
| `01-tokens.md` | 设计变量：颜色、字号、间距、圆角、细线、四套主题、字体与许可 |
| `02-components.md` | 组件规范与交互状态（默认/悬停/按下/禁用/焦点/加载） |
| `03-navigation.md` | 新旧入口对照表、重定向策略、合并入口的数据职责边界 |
| `04-pages.md` | 逐页布局与状态清单（含 6 张效果图已覆盖的页面） |
| `05-missing-pages.md` | 效果图未覆盖的页面与弹窗设计规格 |
| `06-interactions.md` | 交互规则：行内续写建议字、批注锚定、快捷键、窗口折叠 |

| `08-rollout.md` | 分阶段实施顺序与每阶段验收标准 |
| `09-open-questions.md` | 待确认事项（交接前必须由负责人拍板） |

## 效果图基线

已产出的 6 张效果图（浅色设定集人物详情、浅色写作页、书架首页、深色写作页 + 命令面板、
故事地图、灵感工作室）是**方向性设计稿，不是规格来源**。图中文字与数值未经逐字校对，
实现方以本目录文档为准；图片与文档冲突时，以文档为准，并回报冲突点。

设计稿中存在若干占位内容（人物名、章节名、配色微调），实现时不要照抄文案。

## 一条硬规则

本目录描述的是**界面重组**。任何一页都不改变底层数据表结构。
特别是「设定集」合并入口——它只是把三个既有模块放进同一入口，数据仍然分开存储。
详见 `03-navigation.md`。
