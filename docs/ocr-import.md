# 本地 OCR 与疑点复核

本功能从 1.0.5 开始提供。普通 PDF 视觉识别默认关闭，本地 OCR 与付费疑点复核分开操作。

## 使用流程

1. 在知识库导入选择 PDF，读取方式选择“本地 OCR ＋ 疑点复核”。
2. 设置 PDF 页码范围。默认只读第 1～15 页，避免未经准备就对长书启动数小时任务。页码是 PDF 页码，不是书上印刷页码。
3. 点击“开始读取”。在本机重新识别页面图像，不将 PDF 的旧文字层当成正确答案。原文字层保留用于比较。
4. 页面识别完后显示疑点，可按页查看原图区域、原识别和视觉复核候选；需要时手动确认文字。
5. 要使用视觉 AI 时选择已配置的图片模型，设置本轮请求上限，并另行勾选允许发送可疑区域图片。点击“视觉复核待处理项”才调用模型。
6. 处理完成后导入；尚有疑点时，需明确勾选保留待核实标记。不会悄悄删除标记或将未确认内容标为可靠事实。

原有“自动读取”和“全部页面视觉识别”仍保留。选择本地 OCR 时，默认关闭导入后的自动摘要，避免误把“本地识别免费”理解为随后所有处理都免费。

普通 PDF 导入的“允许调用视觉识别”默认关闭，与“设置 → AI 工作流 → PDF 视觉识别”保存同一项本机偏好。未开启时自动模式只读取文字层和已有缓存；遇到无文字的新页面会停止，不发送图片，不把它记成识别成功。“全部页面视觉识别”也需要明确开启。独立的疑点视觉复核使用上面第 5 步的单独授权；摘要属于另一项 AI 操作，需要时可取消自动摘要。

## 本地识别

- 使用固定版本 Tesseract.js 6.0.1 与校验过的简体中文、英文 LSTM 模型，通过 WebAssembly 在本地运行。不要求公司电脑安装 Python，不改低软件脚本安全限制。
- 按页渲染、识别并持久保存结果，识别坐标、原始文字、置信度、页码和旧文字层分别保存。
- 暂停会终止 OCR worker；已完成页保留。重新打开后选择相同文件、本地 OCR 模式和所需页码范围可继续，或选择“读取已识别缓存”。
- 文件指纹、引擎及规则版本参与缓存编号，避免混用不同文件的结果。缓存与原始 PDF 不参与云同步；请保留原 PDF，用于再次查看截图。
- 低置信度、明显异常字符、数字和日期、与原文字层不一致、疑似漏行及表格关系进入疑点列表。置信度和筛查标记都不是正确率统计。

## 视觉复核与费用

- 只有作者明确确认后才发送图片和候选文字给所选模型服务商；账号、API Key 和原 PDF 文件不会作为提示词发送。
- 每组最多 8 个待处理项，使用包含这些条目的原图区域。每轮请求上限 1～100，默认 20；这是请求次数上限，不是金额上限。
- 付费复核不自动重试。接口超时或中断也可能已经计费；已经完成并成功保存的条目不会再次进入待请求列表。
- 返回编号缺失、重复、格式不对或被截断时不改写该组原始结果。
- 普通文字的明确修正保存为独立候选和新文字，原识别始终保留。数字变化、中文数词变化、无法辨认、漏行及表格关系仍待确认，不能仅凭模型声称“确定”直接覆盖。
- “已复核”表示经过所选模型的一轮检查，不代表人工核实或事实正确。
- 可导出包含原文、坐标、置信度、复核候选、模型名称和处理状态的 JSON 记录，也可导出带标记的 Markdown。

## 目前的质量边界

这不是 PP-StructureV3 完整版面解析系统，不声称能够准确重建复杂合并单元格、双栏阅读顺序或手写书法。首轮工程验证采用可在浏览器及桌面沙箱内离线运行的引擎；额外中文模型浏览器接口因其依赖需要放宽脚本执行限制而未接入。

以提供的旧地方志为例，选取 15 个代表性页面进行本地初读，约耗时 190 秒（每次单页重新初始化引擎，3.5～20.2 秒/页）。得到 369 行识别候选，其中 340 行触发保守筛查，包含大量数字与原文字层差异；**这不是 340 行都识别错了，也不是准确率指标**。封面书法、目录和部分地名仍明显存在误字，不能称为免校对高精度结果。

未消耗用户付费 API 验证整书或真实视觉复核后的准确率。视觉复核的授权、裁图、请求上限、取消、返回校验与保存流程已用模拟接口测试。使用真实模型时应先用少量代表页比较效果和费用，再扩大页码范围；不承诺只需处理少数疑点。

## 开发与构建

```bash
npm ci
npm run prepare:ocr
npm run dev:vite
```

模型固定在 `resources/ocr/manifest.json` 指定的版本，SHA-256 校验失败则停止构建。`build:renderer` / `build` 会先校验模型；构建产物含本地模型、worker、核心文件和许可证，使用时不访问 CDN。识别资源增加约 45 MB 未压缩文件体积；1.0.5 Windows 安装包约 144 MB。

测试覆盖本地 worker 取消、缓存隔离与续读、低置信度筛查、数字改动保护、视觉授权、单轮请求硬上限、不自动重试、缺项/截断回复、原图查看与人工确认。浏览器、Windows Electron `file:` 沙箱及 1.0.5 打包程序的 `app.asar` 资源均验证本地读取；未在用户现有安装上执行覆盖安装或卸载。
