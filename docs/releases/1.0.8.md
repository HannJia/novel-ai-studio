# 墨笺 1.0.8

发布日期：2026-10-22（北京时间）。

本版本在 1.0.7 的界面和本地优先写作基础上，完善长篇写作流程、云同步配置和自动更新体验。

## 主要变化

- 增加可按作品调整的篇幅策略，统一章节生成、编辑器状态、完成检查和篇幅候选处理；保留原稿，候选确认后才写入。
- 增加长章节全文审核覆盖，按分段和全章关系复核记录覆盖状态；正文或设定变化后旧审核结果自动失效。
- 云同步支持首次下载、逐项上传确认、冲突保留、配置恢复和并发编辑保护；模型配置可单独加密同步，恢复前后会复查本机变化。
- 自动更新支持后台下载、更新就绪提示、保存保护和安装前确认；设置页与主界面共享安装流程。
- 改进角色库头像、人物关系图、知识库和编辑器辅助体验，补充相应数据迁移、备份和回归测试。
- 增加开发同步、自动备份和本地模型团队桥接工具文档；这些工具不会上传私人稿件、数据库或密钥。

## 下载与提醒

- Windows x64 安装包：`AI-Novel-Writer-1.0.8-x64.exe`。同次构建提供 `latest.yml`、`.exe.blockmap` 和 `.exe.sha256`。
- 已安装版本可在“设置 → 软件更新”中检查并安装，也可以从 GitHub Releases 下载。
- 安装包尚未代码签名，请从本仓库发布页获取并核对 SHA-256；不要关闭系统安全防护。
