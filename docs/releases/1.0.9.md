# 墨笺 1.0.9

发布日期为 2026-11-13（北京时间）。

## 主要变化

- 全面采用“朱批”V3 界面，覆盖书架、新建、写作台、结构规划、典籍、审校中心、自动写作和设置。提供宣纸、护眼、夜墨主题、页边朱批、选区工具条、专注模式与命令面板。
- 创作流程接入 V2 作者主导架构。作品契约与规划由作者确认，多方案骨架可比较、混合并保留来源。AI 正文修改与故事变化先形成候选，故事变化逐条接受后写入正式记录（Canon）。
- 全章审校记录分段覆盖、引文与问题处理状态，正文或设定变化后提示审核失效。定稿前核对保存、故事时间、篇幅、有效审校、阻塞问题、总结与候选处理状态。
- 长篇记忆按章节组织人物知情、有向关系、事件因果、伏笔与时间线，保留来源和修改历史。写作上下文组合正式记录、相关记忆与挂载资料，并隔离未来章节信息，支持全书、分卷和场景回顾。
- 自动写作可设置章节范围、Token 预算、请求上限与作者检查点，查看候选稿、流水线和预算账本，支持暂停、停止与中断恢复。单章篇幅的下限、目标和上限在自动写作页设置，运行中及可恢复任务期间锁定。

## 本轮修复

- 篇幅设置按事务保存，失败保留输入以便重试，切换作品或并发编辑时核对所属作品。
- 短章生成增加推理与正文的输出空间，预算账本修正预留用量的重复计算。
- 章节计划遵守模型配置的输出上限，截断结果会提示失败。短篇可减少远期规划，分卷卡片正确显示目标、冲突和收束。
- 异常结束的自动生成候选持久保存结束原因，重新打开或继续任务后仍等待作者处理。编辑候选后清除旧生成标记，候选接受后才写入章节正文。
- 修复窄窗口中的任务按钮裁切和目录遮挡案头，统一章节标题展示，使用人物与事件名称展示候选，改善书架续写和云同步导航。
- 云冲突处理遇到远端版本再次变化时，重新读取当前本地内容并刷新冲突记录，要求作者重新选择，保留冲突备份。
- 强化 DOCX 导入的样式读取与路径处理防护，Mammoth 固定为 1.13.0。

## 安装与升级

Windows x64 安装包名称为 `AI-Novel-Writer-1.0.9-x64.exe`。配套文件为同次构建的 `latest.yml`、`AI-Novel-Writer-1.0.9-x64.exe.blockmap` 和 `AI-Novel-Writer-1.0.9-x64.exe.sha256`，四项附件来自本次构建。

升级前先使用“备份项目”。已安装版本可通过“设置 → 软件更新”检查更新，正式发布后的下载入口见 [GitHub Releases](https://github.com/HannJia/novel-ai-studio/releases/latest)。
