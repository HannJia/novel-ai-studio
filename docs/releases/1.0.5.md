# AI Novel Writer 1.0.5

发布日期：2026-09-19（UTC），北京时间 2026-09-20。

本版集中修复公司 / 家中跨电脑测试发现的问题：未成书灵感续聊、长对话设定整理、账号密码管理、PDF 识别与费用控制，以及自动更新提示。

## 灵感、同步与账号

- 修复长对话超限后“整理设定”也被拦截的循环，改为按时间顺序分批整理并显示进度，原聊天完整保留。
- 最近 5 个未成书灵感会话迁移到本机数据库并纳入云同步和项目备份，包含未发送草稿、参考知识库、搜索开关和已整理上下文。
- 两端同时编辑同一会话时保留双方版本，不直接覆盖；云端更新仍在书架或设置页、AI 任务结束后合并。
- 注册及密码恢复最低 6 个字符，增加重复密码确认；登录后可验证当前密码并修改，成功后所有设备需重新登录，不删除作品。
- 普通界面隐藏同步服务器地址及编辑入口，保留默认服务与本机账号绑定。API Key 不同步。

## 知识库与 PDF

- 修复 PDF.js 中文 CMap、标准字体和 JBIG2 / JPEG 2000 解码资源缺失，避免读不到文字层、正文渲染成白图。
- 图像解码失败时停止，不把失败页面发给 AI；旧版空白视觉缓存重新检查，保留已有非空文字结果。
- 普通 PDF 视觉识别默认关闭。设置页和导入页可明确开启；关闭时可读取文字层及缓存，无文字的新页面提示改用本地 OCR，不自动调用视觉模型。
- 增加逐页预览、有效文字页 / 空白 / 缺失缓存统计、预计导入条数、只读缓存和文本导出；可疑的不完整结果需要额外确认。
- 增加“本地 OCR ＋ 疑点复核”，可选 PDF 页码范围，默认先读 1～15 页；本地引擎、模型和字体解码资源随安装包提供，无需另外安装 Python。
- 本地识别保留坐标、原始文字、置信度和旧文字层。经用户单独授权后，视觉模型只复核疑点所在区域，每组最多 8 项，每轮最多 1～100 次请求（默认 20），不自动重试。
- 原文与模型候选分别保留；数字变化、表格关系、无法辨认等仍标记待确认。支持查看原图、手工确认及导出复核记录。

## 设置与更新

- 内置写作技能可查看、编辑和保存，可恢复内置规则；保存后用于后续对应任务。
- “向量记忆”更名为可选的“语义检索增强”。关闭不影响结构化记忆、故事时钟、数值计算和本地检索。
- 更新检查失败后按 1、5、15、30、60 分钟退避重试，并在恢复联网、窗口激活或休眠恢复后按需补查。
- 已查到新版但更新清单获取失败时保留版本提示，允许重试或打开发布页；仍不自动下载、安装或跳过校验。

## 下载与升级

- Windows x64：`AI-Novel-Writer-1.0.5-x64.exe`。
- 同次构建提供 `.exe.blockmap`、`.exe.sha256` 与 `latest.yml`。
- 旧版可在“设置 → 软件更新”手动检查，或从发布页下载安装。旧版自动检查未提示时，手动检查可作为升级入口。
- 建议先备份项目；两台电脑都升级到 1.0.5 后再使用未成书灵感续聊。
- 已有 API Key、作品和账号继续留在原用户数据目录，不内置开发者的密钥、登录信息、PDF 或私人作品。
- 安装包尚未代码签名，请核对来源和 SHA-256，不要关闭系统安全防护。

## 质量与费用

- “读取成功”不等于文字正确。有文字层的 PDF 可快速提取，但其中旧 OCR 的误字、错行和数字错误不会自动消失。
- 本地 OCR 不收模型调用费用，但仍占用电脑时间；旧地方志的书法、目录、表格和地名仍可能识别错误，不能承诺免校对或百分之百准确。
- 15 页代表性样本的本地初读约耗时 190 秒，369 行中 340 行触发保守疑点规则。疑点数不是错误率，真实视觉复核后的准确率未验证。
- 视觉识别、疑点复核及摘要可能消耗所选服务商额度。请求上限不是金额上限；超时或中止的请求也可能已计费。原 PDF 和 OCR 缓存不跨电脑同步。
- 云同步仍是测试服务，每账号 100 MiB、单个文档 50 MiB；非端到端加密，不代替离线备份。

## 验证范围

- 80 个测试文件、446 项前端及桌面逻辑测试通过；类型检查、前端构建通过，后端 16 项测试通过。
- 两个独立浏览器通过真实 HTTPS 验证未成书会话及草稿往返、6 位密码注册、改密撤销登录、作品冲突处理；未使用真实用户作品。
- 使用 857 页原 PDF 验证本地文字读取、857 条导入与刷新保存，约 19 秒，AI 请求为零；模拟旧空白缓存恢复通过。
- 本地 OCR 样本、授权开关、裁图、复核请求上限、暂停续读、人工确认、带标记导入及桌面 / 窄窗口布局已验证。视觉模型回复使用模拟接口，没有消耗用户付费额度。
- Windows x64 NSIS 构建、打包程序启动、1.0.5 版本、预加载桥接、沙箱隔离、加密会话读写与真实 HTTPS 连接通过。
- 包内 `app.asar` 的 PDF 解码和本地 OCR 资源在 Electron `file:` 环境读取通过，外网请求为零。294 个应用文件与本机构建逐一比对，未携带配置、数据库、密钥或私人文档。
- 更新下载器的正常下载和篡改拦截通过；安装包、更新清单大小及 SHA-512 一致。服务端备份后升级至 1.0.5，健康检查正常。
- 未在用户现有安装上进行覆盖安装或卸载测试。
