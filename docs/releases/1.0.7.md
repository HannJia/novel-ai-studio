# 墨笺 1.0.7

发布日期：2026-10-10（北京时间）。

软件更名为“墨笺”，界面按“东方书卷·宣纸墨色”风格整体重做。功能、数据格式和更新通道不变。

## 主要变化

- 更名为“墨笺”（原 AI Novel Writer）。窗口标题、页面、助手自我介绍和备份报错文字同步更新。安装包与程序文件名暂沿用 `AI-Novel-Writer`，应用标识、数据目录、备份格式和更新通道均不变，可直接覆盖升级，已有作品与设置保持原样。
- 三套主题改为宣纸、护眼、夜墨，设置在顶栏右侧的色块中切换。标题与编辑器正文使用宋体，主色为朱砂红，AI 与信息类元素使用黛青色。
- 顶栏改为印章标识加“书架 / 知识库”导航，右侧显示云同步状态。书内侧栏增加图标和数量角标，并在底部显示全书字数与目标进度。
- 书架改为线装书风格封面，同一本书的封面颜色固定，书名竖排；按“全部 / 写作中 / 已归档 / 回收站”分栏，右下角提供“继续写作”入口。
- 章节编辑器正文居中显示在纸面上；写作辅助面板打开时不再遮挡正文。工具按钮由 emoji 改为线性图标。
- 创建向导、灵感对话、剧情规划、知识库、角色库、数据面板、章节列表和设置页统一样式。知识库详情页改为左侧分类、右侧条目；角色卡使用印章式头像；设置页右侧增加分区导航，点击可跳转。
- 界面中的装饰性 emoji 换成印章字或淡墨远山图。知识库条目的分类统一显示中文名称。

## 下载与提醒

- Windows x64 安装包：`AI-Novel-Writer-1.0.7-x64.exe`。同次构建提供 `latest.yml`、`.exe.blockmap` 和 `.exe.sha256`。
- 在已安装版本的“设置 → 软件更新”检查新版，或从 GitHub Releases 下载。本版不修改已有作品内容，升级前仍建议备份项目。
- 本版不含自托管同步服务器的自动部署，服务端仅同步版本号，与 1.0.4 及以上客户端保持兼容。
- 安装包尚未代码签名，请从本仓库发布页获取并核对 SHA-256；不要关闭系统安全防护。

发布前执行前端及桌面逻辑测试、类型检查、Windows x64 打包启动、安装包内容及更新清单校验。
