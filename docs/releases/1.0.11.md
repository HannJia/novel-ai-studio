# 墨笔生花 mobish 1.0.11

发布日期为 2026-11-14（北京时间）。

## 写作与审校

- 正文输入时将光标保持在编辑区约三分之二高度，较短正文受实际滚动边界限制。定稿检查保留在正文末尾，随内容增加向下移动，继续滚动即可查看。
- 底部“排版”支持字号、段落间距和字间距，可恢复默认并保存本机偏好；不改变书稿正文。
- 案头默认显示顾问，审校时切换审校面板，批注与候选按实际内容显示，减少空白区域。移除重复状态和多余说明。

## 灵感与创建

- 起点页只选择创建方式，下一步统一填写灵感。有内容时点击“发送灵感并开始讨论”直接发送，返回再进入不重复发送，并保留其他未发送草稿。
- “整理设定”更新当前可编辑设定并压缩已聊上下文，留在对话中继续讨论；后续回复引用最新设定。“完成”进入详细检查，不额外调用模型。完整历史保留，并显示新增讨论待整理状态。
- 每轮提供三个后续问题，点击直接继续讨论，保留输入框草稿。必要时最多发起一次问题补齐请求，失败保留原回答并提供备选问题。
- 对话消息内部滚动，输入区置底，回车提示与发送按钮同排；窄窗口可切换对话和设定。修复上下文提示越界及知识库保存回执导致建议消失。
- 创建输入增加离开和刷新保护；更换搭配支持取消，恢复原入口、写作方式和步骤。

## 设置与更新

- 模型、技能和新增条目按条目保留当前页面内的未保存编辑，显示未保存标记，取消、收起和离开时提供保护；切换后的迟到请求不会覆盖当前编辑。
- 设置分区同步 URL，支持深链接、刷新和浏览器前进后退。写作技能整张卡片可点击选择。
- 软件更新并入“关于”。关闭自动下载后仍保留版本检查，发现新版本显示版本红点；下载就绪后提供安装提示，由用户决定安装。

## 安装与数据

安装包为 `mobish-1.0.11.exe`，面向 Windows x64，包含桌面运行环境、字体及本地 OCR 资源，无需另装 Node.js。应用与快捷方式显示“墨笔生花”，程序和首次安装目录末级使用 mobish。

1.0.10 用户可在软件内检查更新，也可手动下载安装。1.0.9 及更早客户端使用旧安装包命名规则，请手动下载。现有原生 V3 数据位置保持不变；退役格式数据不读取或转换，旧文件保留原处，更新前请备份项目。

模型和技能的未保存编辑仅暂存在当前页面内存；离开或刷新前请保存。AI 功能需要自行配置模型服务及额度。生产云同步实体设备冲突验收仍延期，本次不宣称该项已经完成。

安装包尚未进行代码签名，发布页提供 SHA-256 校验文件。
