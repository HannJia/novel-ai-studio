# AI Novel Writer 1.0.6

发布日期：2026-09-26（北京时间）。

本版改善长篇写作的灵感、规划和章节完成流程。

## 主要变化

- 灵感对话在上下文接近上限时自动分批压缩较早的消息，保留原始聊天记录和未发送草稿；发送按钮旁显示上下文用量。整理设定仍单独生成书籍设定。
- 从灵感消息存入知识库时，可提取和编辑具体知识条目；提取失败时仍可选择保存原文。
- 剧情规划减少重复完成提示，章节生成与内容审查显示任务进度。任务完成后自动收起已完成状态，未完成项继续可见。
- “完成本章”统一进行结尾检查、内容审查、必要的局部修订和章节记忆更新。局部修订只接受能唯一匹配原文的片段，保留原稿版本；修订失败不会覆盖正文。
- 修订输入框只展示具体需要处理的问题，不包含通过项、无问题检查或编辑润色建议；完整报告仍可在下方查看。
- 在工作台切换到章节列表等页面时，正文生成和完成本章继续针对原章节运行；手动停止仍会取消请求。关闭软件或刷新页面不保证任务继续，已保存的正文和审查结果可用于重试。
- 设置以覆盖层打开，不会退出灵感对话；云同步在开发浏览器的常用端口下可连接。修复桌面退出确认事件重复处理。

## 下载与提醒

- Windows x64 安装包：`AI-Novel-Writer-1.0.6-x64.exe`。同次构建提供 `latest.yml`、`.exe.blockmap` 和 `.exe.sha256`。
- 在已安装版本的“设置 → 软件更新”检查新版，或从 GitHub Releases 下载。建议升级前备份项目；本版不修改已有作品内容。
- AI 检查、局部修订、自动上下文压缩仍可能消耗模型额度。网络中断或接口拒绝请求时任务会停止，不会自动进行无限重试。
- 本版不包含自托管同步服务器的自动部署。服务端源码已更新，但已有服务器需单独维护。
- 安装包尚未代码签名，请从本仓库发布页获取并核对 SHA-256；不要关闭系统安全防护。
