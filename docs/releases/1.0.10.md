# 墨笔生花 mobish 1.0.10

发布日期为 2026-11-13（北京时间）。

## 主要变化

- 软件更名为“墨笔生花”。Windows 安装向导和程序文件使用 mobish，桌面与开始菜单快捷方式显示“墨笔生花”。首次安装默认目录末级为 mobish，已安装用户优先沿用原安装目录。
- 完成原生 V3 切换。书架、新建、写作、规划、典籍、审校、自动写作与设置，以及人物、数据、章节、灵感、总纲和知识库管理采用统一的 V3 页面、路由和主题。退役界面、旧路由、主题桥接和历史数据升级适配已移除。
- 保留作者主笔、AI 候选与逐项确认入典、全章审校、按章长篇记忆、自动写作检查点和恢复、当前正文历史与故障恢复。创建就绪印章使用 32px 单字“墨”。
- 精简桌面运行依赖。安装包仍包含 Electron、页面资源、离线字体、本地 OCR 资源及必要运行库，安装后可直接本地写作，无需安装 Node.js。

## 本轮修复

- 选区修订使用作者配置的模型输出上限，解决短选区的推理占满输出预算问题。采纳改稿后提示重新审校。
- 审校列表仅为已有报告、签名或部分覆盖的章节构造比较上下文，减少长书重复计算。已有审校继续核对当前正文与规划来源。
- 作品契约探索明确合法枚举，总纲与分卷按批准的字数规模、类型和风格生成，短篇未设置章长时要求作者选择。
- 分卷结果落盘前核对请求时的契约、方向与规划基线，避免晚到结果覆盖作者修改。创建页与规划页统一分卷卡片布局。
- 同步更新器、下载验证、包审计与 GitHub 首页说明中的 mobish 安装包文件名。

## 安装与数据边界

下载 `mobish-1.0.10.exe`，按向导安装。配套文件为 `latest.yml`、`mobish-1.0.10.exe.blockmap` 和 `mobish-1.0.10.exe.sha256`，均来自同次构建。平台为 Windows x64。

**1.0.9 及更早版本请手动下载安装本次更新。** 旧客户端按原文件名查找安装包，打开发布页即可下载 mobish 安装器。1.0.10 起客户端按新名称识别后续更新。

**原生 V3 使用独立存储。** 从旧正式版首次进入时为空书架，需要重新配置模型并登录云账号。旧格式作品、项目备份和云文档不再读取或升级，旧文件保留原处。更新前请在原版本导出正文并备份旧作品。

已有原生 V3 的作品仍使用原用户数据目录及 `projects-v3`，更名不会另建一套 V3 作品库。安装升级身份及公开更新仓库继续使用现有值。
