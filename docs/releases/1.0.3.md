# AI Novel Writer 1.0.3

发布日期：2026-09-17。

本版集中完善知识库导入与对话：支持扫描 PDF 视觉识别，灵感对话可以参考软件知识库、整理并保存知识条目；增加助手的软件操作上下文，并将组件默认交互改为中文。

## 扫描 PDF 与长资料

- 单个 TXT、Markdown、DOCX、EPUB、PDF 文件上限提高到 100 MB。
- PDF 默认读取文字层，仅在页面无文字时调用视觉模型；也可对文字层错误或不完整的文件选择整份视觉识别。
- 在知识库导入中选择现有模型，点击“开始读取”。沿用所选接口地址和密钥，使用 OpenAI 兼容的图片消息格式，不额外接入 OCR 平台。
- 分页显示进度，可暂停、继续。每页完成后缓存文字，关闭后选择同一文件、相同读取方式可续读；文件内容不同不会混用缓存。
- 不把截断回复、解析失败或中断页面记作完成；已成功缓存页无需重复调用模型。
- 阅读完成后可以修改文本预览，再确认导入。支持关闭导入后的自动摘要；启用时控制并发，避免长文档同时发起过多请求。

## 灵感与书内助手

- 灵感模式默认参考书架知识库，可自行选择或清空，读取相关摘要和原文片段。
- 参考范围保存在最近五个灵感会话中；不会因此自动改变新小说的挂载范围。
- 灵感回复和书内助手回复新增“存入知识库”：选择已有库或新建库，编辑标题、分类、内容和标签，确认后写入本机。
- 保存成功后显示软件回执，写入失败可重试，避免重复创建。
- 助手增加软件身份、知识库和编辑器等功能说明。书内助手只读取本书挂载资料，并获得当前编辑章节的有限正文快照。
- 知识库修改或新增条目后，下一轮对话立即使用当前资料。

## 中文交互与修复

- 中文确认、取消、选择器与日期；设置页参数和写作技能标签中文化。
- 修复单行、短事实资料导入被跳过的问题。
- 导入读盘失败或取消时不会用旧文件文本冒充新结果。

## 下载与升级

- Windows x64 安装包：`AI-Novel-Writer-1.0.3-x64.exe`。
- 同次构建提供 `latest.yml`、`.exe.blockmap` 和 `.exe.sha256`。
- 1.0.2 用户可在“设置 → 软件更新”检查；旧版也可从本发布页手动下载安装。
- 更新前建议备份项目。安装包不携带开发电脑的密钥或小说数据，升级会沿用你本机已有配置。
- 安装包未代码签名，请核对下载来源及校验值。

## 限制与隐私

- 视觉识别需要模型和中转接口支持图片消息。开始前会提示页面图片发送给所选服务商及可能产生的费用。
- 本版没有新增搜索服务或云端同步；PDF 识别与联网搜索开关相互独立。
- 提取文字最多 500 万字符，PDF 最多 1000 页；压缩文档保留解压大小与路径检查。
- 识别可能出错，尤其是手写、低清晰度扫描、复杂表格及数字，请核对后导入。
- 自动模式不会识别已有文字层之外的插图或漏字；这类文件应选择全部页面视觉识别。
- 已完成页的缓存只保存文字和处理信息，不保存密钥、原 PDF 或页面图片。缓存不包含在项目备份中，确认导入的知识条目包含在备份中。
- 重新打开软件后须重新选择本地 PDF；不会未经确认自动恢复付费识别。
