# AI Novel Writer 1.0.4

发布日期：2026-09-17（UTC），北京时间 2026-09-18。

本版新增可选云同步：在公司写完，回家登录同一账号继续。仍然优先保存在本机，不登录也能使用原有写作功能。

## 新增功能

- 设置页新增云同步、邀请码注册、账号恢复和手动同步；管理员可创建有效期 7 天、1～20 次使用的邀请码。
- 首次开启需确认上传当前书架；账号与本机书架绑定，避免登录其他账号时误传作品。
- 同步整本小说的正文、版本、大纲、规划、角色、数据面板、故事时钟、书内对话与灵感存档，以及知识库原文、摘要、分类和挂载关系。
- 自动同步约每 30 秒检查一次；联网恢复、窗口重新获得焦点、页面切换也会触发检查。
- 编辑器内继续本地保存和上传；云端更新等待返回书架或设置页且 AI 任务结束后再合并。
- 两边同时修改时不自动选一边覆盖：保留本机及云端版本，可分别导出，选择后仍保留冲突备份。
- 密码哈希、HTTPS、桌面加密会话、账号隔离、配额、请求大小和注册登录限流。
- 提供自建服务、系统服务、证书续期和数据库备份配置。

## 开始使用

1. 从管理员取得邀请码，在“设置 → 云同步 → 邀请码注册”创建账号。
2. 单独保存账号恢复码。忘记密码时可用它重置；使用后会生成新的恢复码。
3. 确认同步当前书架并开启自动同步，等待“已同步”。
4. 在第二台电脑登录同一账号并开启同步。首次下载在书架或设置页完成。
5. 换电脑前检查同步状态；遇到冲突先导出需要保留的版本，再决定采用哪份。

云账号不提供 AI 额度。新电脑仍需自行配置模型服务与 API Key。

## 下载与升级

- Windows x64：`AI-Novel-Writer-1.0.4-x64.exe`。
- 同次构建提供 `.exe.blockmap`、`.exe.sha256` 和 `latest.yml`，供校验与软件内更新使用。
- 1.0.2 及以上安装版可在“设置 → 软件更新”检查，也可手动下载安装。
- 安装包不包含任何开发电脑的账号、邀请码、模型密钥或小说数据。升级继续使用原来的本机资料。
- 尚未进行代码签名，请核对发布来源与校验文件，不要关闭系统安全防护。

## 限制与隐私

- 默认同步服务器为当前测试服务，也可填写自建的 HTTPS 服务地址。注册需要邀请码。
- 每账号 100 MiB，单本小说或单个知识库 50 MiB，最多 2000 个文档记录（含删除记录）。小说历史版本计入大小；超限明确报错，不截断正文、不删除本地文件。
- 同步以整本书、整个知识库为单位，不是逐字传输或多人实时编辑。不同电脑修改同一本书的不同章节也可能需要处理冲突。
- 不同步模型 API Key、原始上传文件、PDF 识别缓存、应用主题、模型任务分配和未创建成书的灵感会话。已存入书内的灵感记录会同步。
- 浏览器会话保存在当前标签会话中；Windows 桌面会话由操作系统加密保存。登录有效期 30 天，同一账号最多 8 个有效设备会话。
- 使用 HTTPS 传输，但不是端到端加密；服务器运营者能够访问云端正文和服务器备份。
- 云端内容合并前保留本机恢复点；服务端每天保留一致性备份，滚动保存最近 3 份。这些备份仍在同一台服务器，不是异地备份，也不替代作者自己的“备份项目”。
- 当前同一本机书架不提供解绑后换号功能。不同账号请使用独立系统用户环境。
- 服务不可达时继续本地写作；没有同步成功的修改不会自动出现在另一台电脑上。
