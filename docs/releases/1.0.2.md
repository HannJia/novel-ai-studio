# AI Novel Writer 1.0.2

本次新增 Windows 桌面版的软件更新功能。今后发布带完整安装附件的 GitHub 正式版本，软件就能提示更新，也可以在设置里手动检查。

## 下载与升级

- 安装包：`AI-Novel-Writer-1.0.2-x64.exe`。
- 自动更新清单：`latest.yml`。
- 同时提供 `.exe.sha256` 校验文件和 `.exe.blockmap`。
- 下载入口：[1.0.2 发布页](https://github.com/HannJia/novel-ai-studio/releases/tag/v1.0.2)。

**1.0.0 / 1.0.1 用户需要先手动安装一次 1.0.2。** 旧版本没有自动更新入口；装好 1.0.2 后，即可检查后续版本。更新前建议在书架备份项目。安装包尚未代码签名，请核对下载来源。

## 更新内容

- 自动检查：启动后检查 GitHub 正式版本，持续运行期间定期检查，可在设置中关闭。
- 手动检查：新增“设置 → 软件更新”，显示当前版本、最新版本和上次检查时间。
- 新版提示：全局显示可关闭的提示，支持查看更新内容、发布日期和打开发布页。
- 下载安装：点击后才下载，显示进度，支持取消；下载完成不自动重启，需要确认“安装并重启”。
- 保存保护：先保存编辑器未保存的正文，再保存小说、知识库和配置；失败或超时不会继续安装。
- 任务保护：AI 生成、联网对话、后台任务或项目导入仍在运行时阻止安装；准备安装期间不接受新任务。
- 文件校验：校验正式版本号、安装包名称、固定版本下载地址及 SHA-512，拒绝降级、预发布和异常清单。
- 环境区分：浏览器和桌面开发环境不安装更新，显示明确说明与发布页入口。
- 完善软件首页和维护者发布指南，避免只上传安装包而漏掉自动更新清单。

## 注意

- 检查更新需要能连接 GitHub，不需要 GitHub 账号或 Token，也不会上传小说正文和 API Key。
- 以后上传新版时，需要在同一个正式 Release 中上传对应 `.exe` 和 `latest.yml`；只有源码提交或标签不够。
- 网络失败、发布附件不完整或安装程序无法启动时，可在发布页手动下载安装。
- 当前仍是本地优先的软件，没有新增账户系统或跨设备云同步。
