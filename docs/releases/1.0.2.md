# AI Novel Writer 1.0.2

1.0.2 提供 Windows 桌面版的软件更新功能，支持自动提示和手动检查后续正式版本。2026-09-16 修订安装包，加入联网诊断和 Claude 事件流兼容修复，版本号仍为 `1.0.2`。

## 2026-09-16 安装包修订

- 设置页将普通对话测试与联网搜索测试分开，显示所选或自动推测的搜索协议。
- 联网测试需明确确认后发起，可停止并复制诊断，不发送小说内容，不自动切换协议或重复请求。
- 区分接口权限、额度、连接、超时、网页响应、协议不匹配和搜索工具错误；诊断不包含模型密钥或服务商原始错误内容。
- 兼容部分中转站对非流式 Claude 请求返回事件流，保留搜索来源和引用，拒绝把不完整回复当成完整结果。
- 有搜索执行记录但没有可引用来源时，仍显示“未完整验证”，不把模型声称搜索当作已验证。
- 编辑模型时测试可使用已保存的 API Key，无需重复填写；调整窄窗口布局。

**这是同版本安装包替换，不是新的版本发布。** 已安装 2026-09-13 版 `1.0.2` 的用户，需要重新下载同名 `.exe` 并手动安装；软件不会提示同版本更新。安装前请先备份项目并退出软件。

功能源码对应提交 [`aed96df8d2ea0cbee9ebef9468ccb0e0f904c60a`](https://github.com/HannJia/novel-ai-studio/commit/aed96df8d2ea0cbee9ebef9468ccb0e0f904c60a)。原 `v1.0.2` 标签未移动，发布页自动生成的 `Source code` 压缩包仍对应初始发布；开发者请使用上述提交或仓库 `main` 分支。

此次未接入 Exa MCP。搜索仍依赖模型接口和中转站的支持，事件流解析兼容并不保证服务商实际提供了可验证的联网搜索。

## 更新内容

- 自动检查：启动后检查 GitHub 正式版本，持续运行期间定期检查，可在设置中关闭。
- 手动检查：新增“设置 → 软件更新”，显示当前版本、最新版本和上次检查时间。
- 新版提示：全局显示可关闭的提示，支持查看更新内容、发布日期和打开发布页。
- 下载安装：点击后才下载，显示进度，支持取消；下载完成不自动重启，需要确认“安装并重启”。
- 保存保护：先保存编辑器未保存的正文，再保存小说、知识库和配置；失败或超时不会继续安装。
- 任务保护：AI 生成、联网对话、后台任务或项目导入仍在运行时阻止安装；准备安装期间不接受新任务。
- 文件校验：校验正式版本号、安装包名称、固定版本下载地址及 SHA-512，拒绝降级、预发布和异常清单。
- 环境区分：浏览器和桌面开发环境不安装更新，显示明确说明与发布页入口。
- 完善软件首页和维护者发布指南，避免只上传安装包而漏掉自动更新清单。
