# AI Novel Writer 1.0.1

本次更新重点是长篇小说的故事时间、数据记忆与装备属性管理，并改善本机开发时的 API Key 保存体验。

## 下载与更新

- Windows x64 安装包：`AI-Novel-Writer-1.0.1-x64.exe`。
- SHA-256 校验文件：`AI-Novel-Writer-1.0.1-x64.exe.sha256`。
- 下载入口：[1.0.1 发布页](https://github.com/HannJia/novel-ai-studio/releases/tag/v1.0.1)。
- 更新前请在书架执行“备份项目”。浏览器版迁移到桌面版，需要导入项目备份并单独配置 API Key。
- 安装包未进行代码签名，请核对发布者、下载地址及校验值。

在下载目录中用 PowerShell 计算校验值，并与 `.sha256` 文件对比：

```powershell
Get-FileHash .\AI-Novel-Writer-1.0.1-x64.exe -Algorithm SHA256
```

## 本次更新

### 故事时间与成长进度

- AI 从章节中识别明确经过的天数，记录章节时间与故事时钟；不明确的时间可人工校正。
- 数据对象支持基于故事时间的成长规则，可记录作物成熟周期、额外进度和剩余时间。
- 防止重复完成章节导致时间重复推进，新增对象不继承创建前的成长时间。

### 装备与道具记忆

- 在“完成本章”或“扫描变更”时，从正文中提取新物品、属性、归属与使用状态，两种写作模式均可使用。
- 提取结果附带证据，确认后才进入数据面板；没有现成数据对象也能扫描。
- 持有物品与装备生效分开，支持明确的固定值与基础属性百分比加成。
- 基础属性与有效属性分开显示；卸下、转移或删除装备后重新计算，不反复累加到基础值。
- 防止重复扫描录入相同结果，避免切换书籍或修改正文后误写过期结果。

### 上下文与保存

- 故事时间、已确认数据与装备有效属性参与写作上下文和语义记忆。
- 数据库、项目备份与数据版本快照保存新增字段。
- 编辑模型时，API Key 留空不清除原密钥；本机开发配置优先恢复仍可用的会话密钥。
- 软件版本统一为 1.0.1，“关于”页与包版本同步。
- 完善 GitHub 首页的软件介绍、模式区别、安装步骤和隐私说明。

## 使用边界

- 数据提取不是逐字输入时持续运行，也不是无需确认就修改正式数据；AI 识别可能出错，请核对证据。
- 获得装备不等于装备生效；条件触发、复杂乘区等特殊规则目前需要人工记录或核算。
- 没有明确的时间依据时，AI 不能保证推算出唯一准确的故事时间。
- 软件仍处于测试阶段，尚未提供云同步和安装后的自动更新；请定期备份。
- 此次未调用真实付费 AI 接口验证模型输出，生成与抽取质量仍取决于你配置的服务。
