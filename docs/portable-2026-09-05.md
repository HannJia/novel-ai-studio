# AI Novel Writer 免安装版

版本：0.1.0 · 2026-09-05 · Windows x64（64 位）

## 开始使用

1. 下载便携 ZIP，将整个压缩包解压到本机目录。
2. 双击解压目录中的 `AI Novel Writer.exe`。
3. 不要只复制 EXE；同目录的 `resources`、`locales` 和 DLL 等运行文件也必须保留。
4. 无需安装 Node.js，也无需启动开发服务器。
5. 首次使用进入「设置」添加自己的 API 地址、Key 和模型，并分配大纲、正文、审查、对话模型。

发布包不包含作者的 API 配置、书稿数据库或本地恢复副本。AI 功能需要能访问所配置的 API；“联网关”仅表示不请求网页搜索，不代表 AI 模型在本机离线运行。

## 数据与换电脑

- 这是“免安装运行版”，不是把数据自动保存在程序旁边的 U 盘随身版。
- 书稿和模型配置保存在当前 Windows 用户的应用数据目录，删除程序目录不会自动删除这些数据。
- 换电脑前，在书架使用「备份项目」；在另一台电脑使用「导入项目」恢复。
- 项目备份不包含 API Key；另一台电脑需要单独配置模型和密钥，不要直接复制加密配置文件。
- 在已经使用过本软件的同一台电脑上，可能会读到该 Windows 用户已有的测试数据，这是读取本机数据，不是压缩包携带了数据。
