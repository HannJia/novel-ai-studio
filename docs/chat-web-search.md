# 对话窗口联网使用说明

适用位置：小说工作台右下角的「💬 AI 对话助手」，以及「创建新书 → 设定准备方式：灵感模式 → 开始灵感对话」。两个入口各有联网开关，不自动开启正文生成、写作辅助侧栏、大纲生成或设定整理的搜索请求。

## 使用

1. 打开一本书，点击右下角对话按钮。
2. 点击标题旁的小按钮「🌐 联网关」，切换到「🌐 联网开」。
3. 正常发送问题。原生搜索协议允许模型按需搜索；闲聊或纯构思可能不调用搜索。开关默认关闭，按书保存。
4. 回复下方会显示搜索状态；展开「来源」可以查看服务商返回的出处。只有普通文本、没有搜索事件或引用，不会被标成“已经联网核实”。
5. 如果提示接口不支持，打开「设置 → 编辑模型 → 对话联网协议」，按服务商支持的格式选择。一个 API Key、能获取模型列表或模型名称含 Claude/GPT，都不代表中转接口开通了搜索。

书内对话和灵感对话共用「设置 → 模型用途分配 → 对话 / 联网模型」。默认留空并动态跟随「大纲生成」模型；选定专用对话模型后，两个入口无论联网开关开或关都使用它。大纲生成和「整理设定」仍使用大纲模型，不会被此设置改动。

删除已选的对话模型会恢复为跟随大纲；加载旧配置也使用此默认值。联网协议来自本轮实际使用的对话模型，自动匹配只选请求格式，不发额外探测请求，也不保证权限可用：

| 联网协议 | 请求位置 | 说明 |
| --- | --- | --- |
| Responses | 已配置基地址的 `/v1/responses` | `web_search` 工具；关闭服务端存储请求 `store: false` |
| Claude Messages | 已配置基地址的 `/v1/messages` | `web_search_20250305`；每次最多 3 次搜索 |
| OpenRouter | 已配置基地址的 `/v1/chat/completions` | `web` 插件；最多 3 个结果 |
| 搜索专用 Chat Completions | 已配置基地址的 `/v1/chat/completions` | `web_search_options`，要求模型/中转明确支持 |

已填写 `/v1` 的地址不会重复添加。程序不会把你的 Key 转发到另一个未配置域名，也不会失败后偷偷切换供应商、重复搜索或退回普通回答。

## 灵感模式

1. 创建新书时，先选择「AI 模式」或「写作辅助」，再把设定准备方式选为「灵感模式」，点击「开始灵感对话」。两组可自由搭配，灵感整理不改变作者选择的正文创作方式。点击对话上方的「🌐 联网关」开启搜索，此开关仅用于本次灵感会话，与书内对话开关独立。
2. 可以询问近期事件、时代背景、行业变化等。提示词提供当前日期，要求在需要最新事实时使用搜索工具、区分现实与虚构，并标明来源。具体是否支持搜索和是否调用，仍以接口证据为准。
3. 回复下方使用与书内对话相同的来源和搜索状态展示；改变开关只影响下一条消息。停止、退出灵感模式或离开创建页面会取消未完成请求并拒绝晚到结果。
4. 「整理设定并检查」只根据已有对话整理，不再次发送搜索工具。相关参考来源会带入「其他设定」供作者核实；保留最近的最多 12 条安全来源、总计最多 8,000 字符，完整已收到来源仍在聊天记录中。
5. 作者可修改、删除不采用的设定或返回继续讨论，确认后才创建。创建成功后，灵感聊天及其来源保存在新书对话记录中。

注意：「整理设定」不搜索，但仍需调用 API。若大纲模型使用已知强制联网专用别名，会提示改用普通模型，不能假装关闭该模型内置搜索。

灵感输入框支持 **Enter 发送、Shift+Enter 换行**，也保留发送按钮。中文输入法选字时的回车不会发送；空白内容、请求进行中或长按回车不会重复提交。

正文创作方式只按书选择、保存和切换，设置页不再提供全局默认值。新书初始选中「写作辅助」，作者可在创建时改为「AI 模式」，以后仍可在本书编辑器中切换，不影响其他小说。

## 来源显示

- 正文引用只显示网页标题或来源名称，不展开已记录来源的 Markdown 链接或长网址；既有聊天记录同样适用。
- 「来源」折叠区只显示可点击的网页名称，点击名称即可打开原始地址，不另列长网址。接口只有网址而没有可读标题时，显示「网页来源 N」，不伪造标题。
- 来源摘录中的长网址也收敛为名称；底层来源地址与原始回复完整保留，不修改存储证据。书内对话的「复制」复制整理后的可读正文。
- 只处理已记录的来源引用，不静默删掉作者输入或未匹配来源的资料链接。界面继续转义 HTML，并拒绝非 HTTP(S) 或携带凭据的来源跳转。

## 窗口与任务

- 「放大 / 还原」只改变窗口大小。
- 「收起」只折叠窗口，当前请求继续执行；浮动按钮显示后台处理中，结束后提示有新回复。
- 再次展开可看到已经收到的文字或完整结果。
- 点击「停止」、离开当前书籍（包括回书架或进设置）或退出软件会结束客户端请求。书内从章节页切换到规划、数据面板等页面不停止对话。
- 运行中切换联网开关只改变下一条消息；当前请求使用发送时的模式。
- 清空记录需先停止请求，并二次确认。停止不能保证服务商撤销已经执行的搜索或已经发生的计费。

## 隐私与限制

- 「联网关」是“不请求网页搜索”，不是离线模型；普通 AI 对话仍会把当前问题和必要上下文发给已配置 API。
- 书内对话上下文包含部分设定、总纲、角色、最近章节摘要和最近对话，并限制总长度；没有自动发送全书正文。灵感对话发送当前会话和有界来源记录，整理时额外发送待确认设定表单。
- 联网时，服务商可能把查询词交给其搜索服务，也可能额外收费。提示词要求避免把未公开书稿和个人信息用作查询，但这不是服务商侧的数据隔离保证。
- 搜索来源和回复会保存在当前书的对话记录中。灵感整理只提出可编辑的设定草案；程序不自动把外部事实写入正文或章节计划。
- 默认会阻止已知 `:online` / `search-preview` / `search-api` / Sonar 搜索专用模型在“联网关”下发送，避免假装关闭搜索。服务商私有别名或其后台强制搜索行为，客户端无法自动识别或保证关闭。
- 原生联网回复目前完整接收后显示；普通对话保留流式显示。联网过程中可以收起窗口做其他事。
- 本轮协议和界面回归使用本地合成响应，不能替代对某个真实中转服务的权限、额度和搜索结果质量验收。
