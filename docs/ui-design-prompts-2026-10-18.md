## 扩展图册与后续实现约定

- [最新概念图册](../.local-recovery/ui-concepts-20261018/index.html)，采用最新版图片，旧稿仍保留供对照。
- [完整图片索引与最终提示词](../.local-recovery/ui-concepts-20261018/remaining-prompts-final.md)。图片、图册和提示词副本均在本机被 Git 忽略的目录中；跨电脑需单独保存这些视觉资料。
- 分卷与知识条目不依赖配图；以卷序、标题、章节数、摘要或图标组织信息，不保留无图空位。
- 角色库使用随软件提供的水墨头像，根据身份稳定匹配；在编辑资料里可手动改选、恢复自动匹配。手动选择优先，身份变化或 AI 扫描不得无提示覆盖；缺少资源时才以字首兜底。本轮没有交付独立头像素材包或实现匹配逻辑。
- 云同步按每份作品／知识库首次加入时确认，已加入的内容以后自动同步；后来新增且未加入的内容再确认一次。界面采用“待加入同步的内容”，无待确认项目时隐藏。云端配置单独由开关控制，不混入作品选择。
- 取消独立“本机密钥”页，保存状态放在模型配置；配置的跨设备同步统一放在云同步。设置导航保留云同步、模型配置、AI 工作流、语义检索、写作技能、软件更新、关于七项。
- 模型列表不设“全部／写作与对话／向量模型”分类栏，使用小标签说明用途或能力。统一管理连接信息，在“任务分配”增加“语义检索”。语义检索页只显示已分配的向量模型与启用／高级设置，不重复填写接口、密钥或选择模型。
- 支持 Embedding 是具体模型与服务接口的能力，不能通过用途分配获得。实现时应校验能力、过滤不适用的任务选项；向量模型编辑器不显示温度、Top P 等聊天参数。更换向量模型需处理已有索引的兼容性与重建。
- 软件更新图中的版本、发布时间和更新说明是视觉示例，不能视为实际发布记录；安装由使用者确认，提醒不遮挡写作。

## 设计方向与重点

采用“现代书斋”方向：保留纸白、墨色、朱砂与黛青，通过出版物式排版、适量封面色彩和清楚的空间层级提升精致感。装饰集中于品牌和作品封面，正文区域保持平静、清晰。

| 当前情况 | 设计提案 | 预期收益 |
| --- | --- | --- |
| 继续写作在作品网格下方 | 移到标题下方的紧凑首屏入口 | 快速回到上次写作位置 |
| 新建、导入、备份权重接近 | 突出新建，其余降低权重 | 减少操作竞争 |
| 大幅线装封面重复占用网格 | 小型出版封面与作品信息组合 | 保留书卷气，提高信息密度 |
| 编辑器控制项较多，辅助区占宽 | 精简顶部，右侧一次展示一种辅助任务 | 正文成为视觉中心 |
| 设置面板纵向堆叠，索引在右 | 提议左分区索引，模型列表与编辑表单并列 | 更容易定位和填写 |

依据源码：`src/views/NovelList.vue`、`src/views/Workspace.vue`、`src/views/SettingsView.vue`、`src/components/AppHeader.vue`、`src/styles/variables.css`。编辑器结构另由主会话核对 `src/views/workspace/ChapterEditor.vue`，未发送该大文件或用户稿件。

## 三页共用规范

- 画布：1440×900 平面桌面软件截图，无设备外框；另检查 1280×800。
- 色彩：背景 `#F6F1E7`，面板 `#FBF8F2`，正文纸 `#FFFDF8`，文字 `#2B2A28`，次级文字 `#5F5A52`，朱砂 `#B83A2E`，黛青 `#3E5C6B`，边界 `#E3DACB`。
- 字体：界面黑体，标题与长文宋体。页面标题 26～28px，分区标题 18～20px，操作 14px，辅助文字 12～13px；长文正文 18～20px、行高约 1.85。
- 间距：4/8/12/16/24/32px；按钮圆角 6px，卡片 10～12px。阴影轻，正文无明显纹理。
- 每区一个明确主操作，统一细线图标。三页沿用相同导航、品牌和按钮系统，不用无意义统计填满页面。

## 生图后的评审与实现边界

1. 已生成书架、写作与设置三张参考图，先判断书架的品牌、封面比例和首屏操作，再核对整套视觉是否一致。
2. 1280×800 下优先收起右侧AI；左导航可缩为约72px带提示图标栏。书架按可用宽度转三列或两列，正文不通过缩小字体强行塞下。
3. 设置变窄时调整列表与表单排列，必要时先选模型再编辑。所有页面检查焦点、键盘导航、长文本和独立滚动区。
4. 书名、字数和正文均为虚构。章节导航位置、AI标签和设置分区切换是布局提案；图片不能证明控件可点击或功能已实现。
5. 后续实现保留历史版本、改稿候选确认、真实保存反馈和后台静默行为，并验证亮色、护眼、深色主题；图片不能替代对比度、无障碍及数据保护验收。
