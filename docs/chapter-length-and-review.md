# 单章篇幅与全章审校

适用于墨笔生花 mobish 1.0.10。

## 设置篇幅

进入作品的“自动写作”页，填写单章下限、目标和上限，点击保存。默认值为 2000、2200、2400 字，三个值都需是 100–20,000 的整数，并满足下限 ≤ 目标 ≤ 上限。保存失败后保留输入，可重试。任务运行中或仍可恢复时，篇幅设置锁定。

设置按作品保存，供生成指引、篇幅检查和定稿核对使用。写作台显示当前字数与允许区间，篇幅设置入口在自动写作页。

字数按移除空白后的 UTF-16 单位长度统计，包含标点，英文逐字符计。目标用于引导模型，模型可能偏离目标，完成检查会核对允许范围。生成过程保留自然结尾，作者可查看候选并决定采纳。

## 候选与任务恢复

AI 正文先保存在候选稿中。作者接受候选后写入章节，正文改变会使旧审校失效。故事变化由作者逐条决定是否写入正式记录（Canon）。

自动写作支持范围、Token 预算、请求上限与作者检查点。暂停或中断后可恢复，已完成的阶段会复用。输出截断、异常结束或空正文会停止后续处理并显示原因。短章生成预留推理与正文的输出空间，同时遵守作者配置的模型输出上限。

## 审校与定稿

全章审校按原文位置分段处理长章，再根据分段摘要检查全章关系。报告记录已审段数、覆盖字符、引文和问题处理状态。任一必要分段失败或模型输出截断时，报告保留未完成状态。

审校报告绑定正文与设定签名。编辑正文或改变相关设定后，界面提示需要重审，旧报告供作者查阅。重开作品会恢复报告及其失效状态。

定稿前核对保存状态、故事时间、篇幅、有效审校、阻塞问题、总结及待处理候选。作者完成必要处理并确认后，章节才进入定稿状态。

## V3 数据与备份

篇幅配置及审校记录通过当前 V3 项目备份保存和恢复。原生 V3 不再读取或转换旧格式作品、备份与云文档。损坏的覆盖记录会被判定为无效，作者可重新审校。
