# 内置水墨头像

2026-10-18 使用内置 image_gen 为本项目生成五套 4×4 水墨肖像图集，共 80 位虚构成年角色。随应用本地提供，不在使用时调用生图服务，也不上传角色资料。

- `ink-atlas-v1.png`：原有 16 位职业人物。
- `ink-ancient-heroines-v1.png`：16 位古代女主。
- `ink-modern-heroines-v1.png`：16 位现代女主。
- `ink-antagonists-v1.png`：16 位古代／现代反派，男女各半。
- `ink-supporting-v1.png`：16 位古代／现代配角，男女各半。

行列和稳定 ID 由 `src/data/characterAvatars.ts` 定义。界面通过裁剪视窗显示相应格子；关系图使用相同图集坐标。不要重排已有格子或修改稳定 ID，以免改变使用者的手动选择；新增头像另建版本。

身份匹配使用本地关键词及小说题材，身份未知也分配稳定的默认头像；只有图片加载失败时使用字首。手动指定优先，资料编辑可以恢复自动匹配，并按时代、性别、身份分类选择。原始生成图保留于本机生成目录，验收进度见 `docs/ui-revision-2026-10-18.md`。
